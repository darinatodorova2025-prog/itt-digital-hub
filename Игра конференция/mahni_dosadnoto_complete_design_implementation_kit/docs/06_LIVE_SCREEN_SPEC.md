# 06 — Live / Projector Screen Specification

Primary:
1920×1080

Secondary:
1366×768

No marketing nav/footer.

## L01 Collecting

Stage:
`01 · Споделяме`

Headline:
“Какво ви губи време?”

Show:
participants / organizations / ideas.

QR:
large, high contrast, real destination.

Image:
night/twilight infrastructure.

The audience must instantly understand:
scan → participate.

## L02 Organizing

Stage:
`02 · Подреждаме`

Headline:
“Събираме и подреждаме идеите”

Visual:
many → grouped → final themes.

Metrics:
original ideas / common themes / additional AI theme.

No fake progress percentage.

## L03 Voting

Stage:
`03 · Избираме`

Headline:
“Гласуването е активно”

Show top 4–5 themes max.
Large ranking bars.
Vote totals aligned.

Image may sit on right edge / behind quiet area.

## L04 Countdown

Headline:
“Последни 30 секунди”

Huge:
`00:30`

One progress ring.
Minimal chrome.
Night image.
No dashboard clutter.

## L05 Second view

Stage:
`04 · Втори поглед`

Copy:
“Хората вече гласуваха.”
“Сега ИИ разглежда темите независимо.”

Three large lenses.
Completed / active / pending status.

End:
“Вторият поглед е готов.”

## L06 Result

Stage:
`05 · Резултат`

Headline:
“Какво излезе напред”

Visual hierarchy:
~2/3 importance participant result
~1/3 independent AI view.

Primary:
“Изборът на участниците”

Secondary:
“Независим поглед от ИИ”

Convergence:
“Един/Два/Три общи приоритета”

Support:
“Официалният резултат е изборът на участниците.”

Optional quiet action line:
“От резултат към действие”

## Projector rules

- major text readable from distance;
- overlays should be local, not a dark blanket;
- no small body copy blocks;
- maximum 4 rows at shorter height if needed;
- no viewport overflow;
- no false initial background.
