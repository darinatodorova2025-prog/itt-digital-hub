# ViK Event Context

## Purpose
Helps clustering understand professional language, roles and workflows in the Bulgarian water and sewerage sector. It is **not** a normative/legal knowledge base. Never use it to invent a participant problem, cause, desired outcome, solution, requirement or technical fact.

## Expected audience
Primarily ViK designers/design offices, plus water/sewer operators, operations/maintenance, construction/installers, equipment manufacturers, suppliers/distributors, technical sales, consultants, investors/clients/contracting authorities, municipalities/public administration, construction supervision, GIS/CAD/BIM specialists, surveyors, service/maintenance organizations.

Designers may be the majority, but their ideas do not become more semantically true or more important. Role is context, not weighting.

## Typical workflows
Source/input data; surveys/field information; hydraulic calculations; sizing; water supply/sewerage/building systems design; CAD/BIM/GIS; drawings; revisions/versioning; interdisciplinary coordination; specifications; KSS/bills of quantities; reports/documentation; approvals/permitting; authority coordination; equipment selection; product data; tendering/quotations; purchasing/delivery; construction/installation; site changes; as-built documentation; commissioning; operation; maintenance; failures; asset management; field data; repeated copying between systems; search in regulations, project files and product information.

## Interpretation rules
- Same sector != same problem.
- Same workflow != same problem.
- Same software != same problem.
- Same document != same problem.
- Different roles may describe the same problem with different vocabulary.
- Separate proposed solution from underlying pain where possible.
- Missing information remains unknown.
- Do not normalize away meaningful differences.
